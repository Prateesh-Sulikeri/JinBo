# JinBo Chatbot - Quick Start Guide

Get your AI chatbot running in 5 minutes! ⚡

## 🚀 Installation

### Option 1: Automated Setup (Recommended)

```bash
# Make setup script executable
chmod +x setup.sh

# Run setup
./setup.sh

# Start the bot
npm start
```

### Option 2: Manual Setup

```bash
# Install dependencies
npm install

# Start the server
npm start
```

## 📂 Required Files

Ensure you have these files in your project root:

```
jinbo-chatbot/
├── server.js                                  ← Main server file
├── Prateesh_Master_Knowledge_Base_2026.json   ← Your knowledge base
├── package.json                                ← Dependencies
├── public/
│   └── index.html                             ← Chat UI
└── README.md
```

Open your browser and visit:
```
http://localhost:3000
```

You should see the chat interface! 🎉

### 2. Test the health endpoint

```bash
curl http://localhost:3000/health
```

Expected response:
```json

  "message": "JinBo is up and running!",
  "timestamp": "2024-12-30T10:30:00.000Z",
  "version": "1.0.0"
}
```

### 3. Test the chat API

```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello"}'
```

Expected response:
```json
{
  "response": "Hey! I'm JinBo, Prateesh's AI assistant...",
  "intent": "greeting",
  "source": "rule-based",
  "timestamp": "2024-12-30T10:30:00.000Z"
}
```
`source` will be `"rule-based"` unless you've set up a Groq API key (see
"Enable AI Responses" below), in which case it'll be `"ai"`.

### 4. Run automated tests

```bash
npm test
```

You should see all tests passing! ✓

## 🔧 Configuration

### Change Port

Edit `.env` file or set environment variable:

```bash
PORT=5000 npm start
```

### Update Knowledge Base

1. Open `Prateesh_Master_Knowledge_Base_2026.json`
2. Edit the content
3. Save the file
4. Restart the server: `Ctrl+C` then `npm start`

That's it! The bot automatically reloads the knowledge base for both the AI
system prompt and the rule-based fallback.

### Enable AI Responses (Optional)

By default (no `.env` or empty `GROQ_API_KEY`), JinBo runs in rule-based-only
mode - fully functional, zero config. To get real AI-generated responses:

1. Get a free API key at [console.groq.com/keys](https://console.groq.com/keys)
   (no credit card required)
2. Copy `.env.example` to `.env`
3. Set `GROQ_API_KEY=your-key-here` in `.env`
4. Restart the server: `Ctrl+C` then `npm start`

Responses will now show `"source": "ai"` and be generated by Groq's Llama
models, grounded in the knowledge base. If the key is missing, invalid, Groq
errors, or the free tier's rate limit is hit, requests automatically fall back
to `"source": "rule-based"` instead of failing.

## 📱 Integrate with Your Portfolio

### Angular

```typescript
// chatbot.service.ts
import { HttpClient } from '@angular/common/http';

export class ChatbotService {
  private apiUrl = 'https://your-bot.onrender.com/api/chat';
  
  sendMessage(message: string) {
    return this.http.post(this.apiUrl, { message });
  }
}
```

### React

```jsx
const sendMessage = async (message) => {
  const response = await fetch('https://your-bot.onrender.com/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message })
  });
  return await response.json();
};
```

### Plain JavaScript

```javascript
async function chat(message) {
  const response = await fetch('https://your-bot.onrender.com/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message })
  });
  const data = await response.json();
  return data.response;
}
```

## 🐛 Troubleshooting

### Server won't start

**Check if port is already in use:**
```bash
# Linux/Mac
lsof -i :3000

# Windows
netstat -ano | findstr :3000
```

**Kill the process or use a different port:**
```bash
PORT=3001 npm start
```

### "Cannot find module" error

```bash
# Delete node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Knowledge base not loading

**Verify JSON is valid:**
```bash
# Linux/Mac
cat Prateesh_Master_Knowledge_Base_2026.json | python -m json.tool

# Or use online validator
# https://jsonlint.com/
```

### `source` is always `"rule-based"`, never `"ai"`

- Double check the variable name in `.env` is exactly `GROQ_API_KEY` (a common
  mistake is a stray space or typo breaking how it's parsed)
- Check server logs for `[Groq] AI path failed, falling back to rule-based: ...`
  warnings, which explain the specific failure (invalid key, timeout, rate limit)

### Bot gives wrong answers

1. Check intent detection in `server.js`
2. Add more keywords to match patterns
3. Update responses in `Prateesh_Master_Knowledge_Base_2026.json`

## 📊 Performance Tips

### For Production:

1. **Enable compression:**
```bash
npm install compression
```

Add to `server.js`:
```javascript
const compression = require('compression');
app.use(compression());
```

2. **Rate limiting**: already built in on `/api/chat` (default 20 req/min/IP).
   Tune it via the `RATE_LIMIT_MAX`/`RATE_LIMIT_WINDOW_MS` env vars - no code
   changes needed.

3. **Add logging:**
```bash
npm install morgan
```

Add to `server.js`:
```javascript
const morgan = require('morgan');
app.use(morgan('combined'));
```
